Class: RegExpLexer

RegExpLexer(dict, inputopt, tokensopt) → {Object}

new RegExpLexer(dict, inputopt, tokensopt) → {Object}

Creates a RegExp-based lexer from a grammar dictionary. This is the primary constructor for creating lexers from jison-lex grammar.

Parameters:

Lexer grammar definition (object or lex source string)

Examples
const RegExpLexer = require('jison-lex');
const lexer = new RegExpLexer({
  rules: [
    [/\d+/, "return 'NUMBER'"],
    [/\+/, "return 'PLUS'"]
  ]
});
// With module generation
const lexer = new RegExpLexer(grammar);
